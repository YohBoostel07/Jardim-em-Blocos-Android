# Jardim em Blocos — Godot prototype

This project is a separate Godot 4 prototype. The Kotlin Android game remains on `main` and is not modified by this prototype.

## First milestone
- Procedural stylized 3D garden island.
- 9×9 puzzle board with colored 3D blocks.
- Three selectable pieces.
- Touch-to-place interaction.
- Row and column clearing with score.

## Build
The workflow `.github/workflows/godot-android.yml` exports a debug APK from the `godot-prototype` branch. The APK is a prototype and does not yet include the Kotlin game's saved progress, gardens, shop, missions, expeditions, or power-ups.
