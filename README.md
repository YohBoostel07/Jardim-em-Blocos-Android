# Jardim em Blocos 🌿

Jogo casual Android de blocos com tema de jardim. Projeto nativo em Kotlin, compilado pelo GitHub Actions.

## Como gerar o APK
1. Abra a aba **Actions** do repositório.
2. Selecione **Build Android APK and AAB**.
3. Clique em **Run workflow**.
4. Ao terminar, baixe os artefatos **Jardim-em-Blocos-APK** e **Jardim-em-Blocos-AAB**.

O APK de depuração serve para testes. O AAB de release ainda precisa de assinatura de produção antes da publicação na Google Play.
